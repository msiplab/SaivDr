# saivdr for PyTorch

PyTorch implementation of the NSOLT (non-separable oversampled lapped
transform) layers and networks of the [SaivDr](https://github.com/msiplab/SaivDr)
MATLAB package (`+saivdr/+dcnn`).

For the same inputs and parameters, each layer and network gives the same
outputs and gradients as the MATLAB implementation. This is checked
against reference data generated by MATLAB (see [Equivalence with MATLAB](#equivalence-with-matlab)).

## Installation

Requires Python 3.10 or later and PyTorch 2.1 or later. Install PyTorch
first if you need a specific CUDA build (see <https://pytorch.org>), then:

```sh
# From a clone of the repository
pip install ./python

# Or directly from GitHub
pip install "saivdr @ git+https://github.com/msiplab/SaivDr.git#subdirectory=python"
```

Optional extras:

| Extra | Adds | For |
|---|---|---|
| `saivdr[matlab]` | scipy | Exchanging parameters with MATLAB through MAT-files |
| `saivdr[viz]` | matplotlib | `atomic_imshow` |
| `saivdr[test]` | pytest, scipy, parameterized | Running the tests |
| `saivdr[dev]` | all of the above, ruff, build | Development |

## Quick start

```python
import math
import torch
from saivdr.dcnn import create_nsolt_2d

# Equivalent of fcn_creatensoltlgraph2d(..., 'Mode','Analyzer')
analyzer = create_nsolt_2d(
    number_of_channels=(3, 3),  # (ps, pa)
    decimation_factor=(2, 2),  # (decV, decH)
    polyphase_order=(2, 2),  # (ordV, ordH)
    number_of_levels=2,
    number_of_vanishing_moments=1,  # no DC leakage
    mode="Analyzer",
)
with torch.no_grad():
    for p in analyzer.parameters():
        p.normal_(0.0, math.pi / 6)
synthesizer = analyzer.adjoint()  # parameters copied, as fcn_cpparamssyn2ana

x = torch.rand(8, 1, 32, 32)  # N x C x H x W
coefs = analyzer(x)  # (Lv1_Ac, Lv2_Ac, Lv2_Dc)
y = synthesizer(*coefs)
print(torch.dist(x, y))  # perfect reconstruction
```

`mode="Whole"` (the default) returns a network with `.analyzer` and
`.synthesizer`. `create_nsolt_3d` builds the 3-D counterpart. See
[`examples/`](examples) for dictionary learning and the atomic images.

## Conventions

### Array layout

Arrays follow the PyTorch convention. Parameters such as
`decimation_factor`, `polyphase_order` and `original_dimension` keep the
MATLAB order (vertical, horizontal[, depth]).

| Array | MATLAB | PyTorch |
|---|---|---|
| 2-D image, subband | H x W x C x N | N x C x H x W |
| 2-D coefficients | nChs x nRows x nCols x N | N x nChs x nRows x nCols |
| 3-D image, subband | H x W x D x C x N | N x C x D x H x W |
| 3-D coefficients | nChs x nRows x nCols x nLays x N | N x nChs x nLays x nRows x nCols |
| Serialized subbands | nElements x 1 x 1 [x 1] x N | N x nElements |

`saivdr.dcnn.matlab_compat.from_matlab_array` and `to_matlab_array`
convert between them.

### Parameters

The `angles` (learnable) and `mus` (buffer) of the rotation layers are
identical to the `Angles` and `Mus` properties of the MATLAB layers. For
the initial and final rotations, `angles` is `[angles of W0; angles of U0]`.
As in MATLAB:

- with `no_dc_leakage=True`, `mus[0]` is regarded as 1 and the first `ps-1`
  angles as 0, but their gradients are not masked;
- the intermediate rotations built by `create_nsolt_2d`/`create_nsolt_3d`
  have `mus = -1`, so that a network with zero angles is the block DCT.

The layers of a network are kept in `net.layers`, an `nn.ModuleDict` keyed
by the MATLAB layer names, such as `'Lv1_Cmp1_V0'` and `'Lv1_Cmp1_Vh1~'`.

### Exchanging parameters with MATLAB

```python
from saivdr.dcnn import matlab_compat

matlab_compat.load_params(net, "params.mat")  # written by saivdr_export_params
matlab_compat.save_params(net, "params.mat")  # read by saivdr_import_params
```

On the MATLAB side, add `python/tools/matlab` to the path:

```matlab
saivdr_export_params(dlnet, 'params.mat')        % MATLAB -> Python
dlnet = saivdr_import_params(dlnet, 'params.mat') % Python -> MATLAB
```

## Correspondence to MATLAB

| MATLAB `saivdr.dcnn` | Python `saivdr.dcnn` |
|---|---|
| `nsoltBlockDct2dLayer`, `nsoltBlockIdct2dLayer` | `NsoltBlockDct2dLayer`, `NsoltBlockIdct2dLayer` |
| `nsoltBlockDct3dLayer`, `nsoltBlockIdct3dLayer` | `NsoltBlockDct3dLayer`, `NsoltBlockIdct3dLayer` |
| `nsoltInitialRotation2dLayer`/`3dLayer` | `NsoltInitialRotation2dLayer`/`3dLayer` |
| `nsoltFinalRotation2dLayer`/`3dLayer` | `NsoltFinalRotation2dLayer`/`3dLayer` |
| `nsoltIntermediateRotation2dLayer`/`3dLayer` | `NsoltIntermediateRotation2dLayer`/`3dLayer` |
| `nsoltAtomExtension2dLayer`/`3dLayer` | `NsoltAtomExtension2dLayer`/`3dLayer` |
| `nsoltChannelSeparation2dLayer`/`3dLayer` | `NsoltChannelSeparation2dLayer`/`3dLayer` (returns `(ac, dc)`) |
| `nsoltChannelConcatenation2dLayer`/`3dLayer` | `NsoltChannelConcatenation2dLayer`/`3dLayer` (`forward(ac, dc)`) |
| `nsoltSubbandSerialization2dLayer`/`3dLayer` | `NsoltSubbandSerialization2dLayer`/`3dLayer` |
| `nsoltSubbandDeserialization2dLayer`/`3dLayer` | `NsoltSubbandDeserialization2dLayer`/`3dLayer` |
| `nsoltComponentSeparation2dLayer` | `NsoltComponentSeparation2dLayer` |
| `nsoltIdentityLayer` | `NsoltIdentityLayer` |
| `fcn_creatensoltlgraph2d` | `create_nsolt_2d` |
| (none) | `create_nsolt_3d` |
| `fcn_creatensoltlgraphs2d` (deprecated) | `creatensoltlgraphs2d` (deprecated) |
| `fcn_createsdiplgraph2d` (deprecated) | `createsdiplgraph2d` (deprecated) |
| `fcn_cpparamssyn2ana` | `copy_params_syn2ana` (and `copy_params_ana2syn`, `adjoint()`) |
| `fcn_attachserializationlayers` | `attach_serialization_layers` |
| `atomicimshow` | `atomic_images`, `atomic_imshow` |
| `fcn_orthmtxgen` | `orthmtxgen` |
| `fcn_replaceinputlayers` | not needed: PyTorch networks accept any input size |

Name-value arguments become snake_case keyword arguments, e.g.
`'NumberOfChannels'` → `number_of_channels` and `'NoDcLeakage'` →
`no_dc_leakage`. Errors raise the exceptions in `saivdr.dcnn.exceptions`
(`InvalidDirection`, `InvalidMode`, ...), which derive from `ValueError`.

Differences from MATLAB:

- `create_nsolt_3d` has no MATLAB counterpart. It follows the construction
  of `fcn_creatensoltlgraph2d` with the 3-D layers, extending the atoms in
  the depth, horizontal and vertical directions in this order, as
  `saivdr.dictionary.nsoltx`. Its reference is
  `python/tools/matlab/+refgen/creatensoltlgraph3d.m`.
- The deprecated builders name the layers as `create_nsolt_2d` does
  (with `Cmp1_`).
- Without `patch_size`, `atomic_images` derives the patch size from the
  polyphase order, whereas `atomicimshow` estimates it from the number of
  layers.

## Equivalence with MATLAB

`tests/refdata` holds MAT-files generated by MATLAB with fixed random
seeds: inputs, parameters, outputs, upstream gradients, and the gradients
with respect to the inputs and the angles, for every layer and for
representative networks. The tests compare the PyTorch implementation with
them (rtol 1e-9 in double precision and 1e-4 in single precision), so no
MATLAB installation is needed to run them.

To regenerate the reference data (MATLAB R2022b or later with Deep Learning
Toolbox), run in the SaivDr root folder:

```matlab
setpath
addpath python/tools/matlab
gen_refdata                       % all groups
gen_refdata('Groups',"layers")    % only some groups
gen_refdata('Filter','^Initial')  % only some cases
```

`tests/refdata/manifest.json` records the MATLAB version, the SaivDr commit
and the SHA-256 digest of each file.

## Former implementation

`appendix/torch_nsolt` has moved to `saivdr.dcnn.legacy` without changes in
behavior. It uses the channel-last layout `N x nRows x nCols x nChs` and is
deprecated. Importing it, or `NsoltAnalysis2dNetwork` and
`NsoltSynthesis2dNetwork` from `saivdr.dcnn`, emits a `DeprecationWarning`.
It will be removed in a future release.
