# torch_nsolt (deprecated)

The PyTorch implementation of NSOLT has moved to the `saivdr` Python package
in [`python/`](../../python). Install it with

```sh
pip install ./python
```

and use `saivdr.dcnn`. The modules in this folder only re-export the former
implementation from `saivdr.dcnn.legacy` for existing scripts and will be
removed in a future release.
